### Selected work
- **[WarpServe](https://github.com/shekinahokunbo/warpserve)**: a hand-written CUDA kernel that fuses image resize, normalization and layout conversion, 127x faster than a scalar CPU reference on an NVIDIA T4 with bit-identical output; served with FastAPI, Docker and Kubernetes.
- **[EdgePulse](https://github.com/shekinahokunbo/edgepulse)**: real-time forecasting and anomaly detection with a C++17 core, a lock-free single-producer single-consumer ring buffer between threads, and tests run under ThreadSanitizer and AddressSanitizer in CI.
- **[LearnStream](https://github.com/shekinahokunbo/learnstream)**: an event-driven analytics pipeline on AWS (Lambda, SQS, DynamoDB) with exactly-once processing, measured at 0 failures over 6,898 requests.
- **[Adaptive Learning Platform](https://github.com/rice-apps/adaptive-learning)**: backend and data layer for a GED exam prep platform serving 500+ students, built with RiceApps for the nonprofit Eight Million Stories.

### Also
